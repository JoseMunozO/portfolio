Es la mitad backend de una app completa (Spring Boot REST API + React UI). Centraliza pagos y morosidad, inventario de material, asistencia diaria y notas de alumnos, con permisos distintos para dirección, administración, finanzas y profesorado. La mitad frontend vive en el proyecto **Preschool Admin — Frontend** (mismo producto, repos separados).
