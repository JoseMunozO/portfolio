Konsolapplikation i Java med trelagersarkitektur (Presentation → Business → Data, med DTO:er och mappers). Innehåller bokkatalog med sökning och sortering, medlemsregistrering, lån och återlämningar, böter, recensioner, statistik över mest utlånade böcker och rollbaserade menyer (user, librarian, admin).
